# 🏥 MADHAV Medicare - Hospital Management System

A full-stack Hospital Management System built using the MERN stack.

## 🚀 Project Overview

MADHAV Medicare is a hospital management web application where patients can register, login, book appointments, and view their appointments.

Doctors can view appointments and update their status.

Admins can view hospital statistics and manage hospital data.

## 🛠️ Technologies Used

### Frontend
- React.js
- React Router
- Axios
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
- Cookie Parser
- CORS

## 👨‍💻 Features

### Patient
- Register
- Login
- Patient Dashboard
- Book Appointment
- View My Appointments
- View Profile
  

### Doctor
- Doctor Login
- Doctor Dashboard
- View Appointments
- Confirm Appointment
- Reject Appointment
- View Patient Information

### Admin
- Admin Dashboard
- View Total Patients
- View Total Doctors
- View Appointments
- View Pending Appointments
